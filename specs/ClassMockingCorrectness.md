# ClassMockingCorrectness

## Summary
Test doubles are generated by subclassing: final classes cannot be mocked,
traits and abstract classes need dedicated factory methods, and mocks built
with the constructor enabled need the constructor's required arguments.
Point at the class argument of PHPUnit / Prophecy mocking calls (and PhpSpec
collaborator type hints) that will fail at runtime.

## Detection

### Part A — mocking method calls
Visit every method call (`->` or `::`).

- **D1** The method name, compared case-insensitively as PHP compares
  method names (`CreateMock` qualifies; custos diverges), is one of:
  `getMockBuilder`, `getMock`, `getMockClass`, `getMockForTrait`,
  `getMockForAbstractClass`, `createMock`, `prophesize`, `willExtend`, and at
  least one argument is passed.
- **D2** The call resolves to a method whose `\Class.method` identity
  (declaring class FQN, case-sensitive) is one of:
  - `\PHPUnit_Framework_TestCase`: `getMockBuilder`, `getMock`, `getMockClass`
  - `\PHPUnit_Framework_MockObject_Generator`: `getMock`
  - `\PHPUnit_Framework_MockObject_MockBuilder`: `getMock`
  - `\PHPUnit\Framework\TestCase`: `getMockBuilder`, `getMockForTrait`,
    `getMockForAbstractClass`, `getMockClass`, `createMock`
  - `\Prophecy\Prophet`: `prophesize`
  - `\Prophecy\Prophecy\ObjectProphecy`: `willExtend`
  (A call on a test-case subclass resolving to the inherited framework method
  qualifies; a method re-declared in a subclass does not.)
- **D3** The first argument `A` designates a class `K`:
  - `X::class` where `X` is a class name resolving to a class-like `K`
    (class, interface, trait); or
  - a string literal without interpolation whose content is longer than 3
    characters: replace every `\\` pair in the raw content with a single `\`,
    prefix `\` if missing, look the name up by FQN; `K` is the first match
    **that is final**. Non-final classes named by strings are ignored
    entirely (no report of any kind).
  Anything else (variables, concatenations, `__NAMESPACE__ . '\X'`) → stop.
- **D4** Then by the method name (case-insensitive):
  - `createMock`: `K` is a trait → report **TRAIT**; else `K` final → report
    **FINAL**.
  - `getMockBuilder`: let `P` = the name of the method call chained directly
    on this call's result (`$t->getMockBuilder(K::class)->P(...)`), or none if
    the call is not the receiver of another method call.
    - if `K` is abstract and not an interface: report **USE-ABSTRACT** when
      there is no `P`;
    - else if `K` is a trait: report **USE-TRAIT** when there is no `P`;
    - else if `K` is final: report **FINAL** (regardless of `P`).
    - independently, if `P` is `getMock` (case-insensitive) and `K` has a constructor
      (own or inherited) with at least one parameter lacking a default
      value → report **CTOR**.
  - `getMockForTrait`: `K` is not a trait → report **NEED-TRAIT**.
  - `getMockForAbstractClass`: `K` is not abstract → report **NEED-ABSTRACT**
    (interfaces count as abstract).
  - every other listed method (`getMock`, `getMockClass`, `prophesize`,
    `willExtend`): `K` final → report **FINAL**.

### Part B — PhpSpec specifications
Visit every class declaration.

- **D5** Its direct parent class resolves to a class whose FQN is exactly
  `\PhpSpec\ObjectBehavior`.
- **D6** For each method declared in the class itself, for each parameter:
  walk the class-name references inside the parameter's type declaration
  (including union/nullable/intersection parts) in source order; the first
  one that resolves to a **final** class is reported (**FINAL**), then move
  on to the next parameter (at most one finding per parameter). Class names
  in the default value (`$limit = Sealed::MAX`) are not inspected: PhpSpec
  only builds doubles for type-hinted collaborators.

## Exceptions (no report)
- **E1** Calls with no arguments; unresolved calls; same-named methods of
  other classes.
- **E2** String class names that are short (≤ 3 chars), interpolated, or name
  a non-final class.
- **E3** `getMockBuilder(Abstract::class)` / `getMockBuilder(Trait::class)`
  followed by any chained call (`->getMockForAbstractClass()`,
  `->getMockForTrait()`, `->getMock()`, `->setMethods()`, …).
- **E4** Interfaces passed to `getMockBuilder` (not abstract-class case).
- **E5** `->getMock()` chained on `getMockBuilder` for a class whose
  constructor parameters all have defaults, or that has no constructor.
- **E6** PhpSpec classes extending `ObjectBehavior` indirectly (through an
  intermediate class) are not checked.
- **E7** Part B: final classes referenced only in a parameter's default
  value.
- **E8** FINAL is never reported (Part A or B) when the class
  `\DG\BypassFinals` (package dg/bypass-finals) is known to the project
  index: that tool strips `final` when classes load, so final classes can be
  doubled. TRAIT, NEED-*, USE-* and CTOR findings are unaffected.

## Report
- Range: Part A — the first argument `A` exactly (e.g. `Sealed::class`,
  `'\Sealed'`, `"\\Sealed"` including quotes). Part B — the class reference
  in the parameter (e.g. `Sealed` in `Sealed $s`).
- Severity: error.
- Messages:
  - FINAL: `Final classes cannot be mocked.`
  - TRAIT: `Traits cannot be mocked this way.`
  - NEED-ABSTRACT: `This factory expects an abstract class.`
  - NEED-TRAIT: `This factory expects a trait.`
  - USE-ABSTRACT: `Abstract class: build the double with getMockForAbstractClass().`
  - USE-TRAIT: `Trait: build the double with getMockForTrait().`
  - CTOR: `Mocked constructor needs arguments; pass them or disable the constructor.`

Several findings may land on the same argument (e.g. FINAL and CTOR for a
final class with required constructor arguments).

## Examples

```php
<?php

namespace PhpSpec {
    class ObjectBehavior {}
}

namespace PHPUnit\Framework {
    class TestCase
    {
        public function getMockBuilder($c)          {}
        public function getMockForTrait($c)         {}
        public function getMockForAbstractClass($c) {}
        public function getMockClass($c)            {}
        public function createMock($c)              {}
    }
}

namespace {
    class PHPUnit_Framework_MockObject_Generator
    {
        public function getMock($c) {}
    }

    final class Sealed {}
    abstract class Blueprint {}
    trait Mixin {}
    interface Contract {}
    class Gateway { public function __construct($dsn, $retries = 3) {} }
    class Relaxed { public function __construct($dsn = '') {} }

    class OrderTest extends \PHPUnit\Framework\TestCase
    {
        public function testDoubles()
        {
            $this->createMock(<error descr="Final classes cannot be mocked.">Sealed::class</error>);
            $this->createMock(<error descr="Traits cannot be mocked this way.">Mixin::class</error>);
            $this->createMock(Contract::class);
            $this->getMockBuilder(<error descr="Final classes cannot be mocked.">'Sealed'</error>);
            $this->getMockBuilder(<error descr="Final classes cannot be mocked.">"\\Sealed"</error>);
            $this->getMockBuilder('Blueprint');
            $this->getMockBuilder(<error descr="Abstract class: build the double with getMockForAbstractClass().">Blueprint::class</error>);
            $this->getMockBuilder(Blueprint::class)->getMockForAbstractClass();
            $this->getMockBuilder(<error descr="Trait: build the double with getMockForTrait().">Mixin::class</error>);
            $this->getMockBuilder(Mixin::class)->getMockForTrait();
            $this->getMockBuilder(Contract::class);
            $this->getMockForTrait(<error descr="This factory expects a trait.">Blueprint::class</error>);
            $this->getMockForAbstractClass(<error descr="This factory expects an abstract class.">Gateway::class</error>);
            $this->getMockForAbstractClass(Contract::class);
            $this->getMockClass(<error descr="Final classes cannot be mocked.">Sealed::class</error>);
            $this->getMockBuilder(<error descr="Mocked constructor needs arguments; pass them or disable the constructor.">Gateway::class</error>)->getMock();
            $this->getMockBuilder(Relaxed::class)->getMock();
            $this->getMockBuilder(Gateway::class)->disableOriginalConstructor()->getMock();
        }
    }

    $generator = new PHPUnit_Framework_MockObject_Generator();
    $generator->getMock(<error descr="Final classes cannot be mocked.">Sealed::class</error>);
    $generator->getMock(ArrayObject::class);

    class GatewaySpec extends \PhpSpec\ObjectBehavior
    {
        function it_charges(<error descr="Final classes cannot be mocked.">Sealed</error> $card, Relaxed $log) {}
    }
}
```

## Divergences
- **dg/bypass-finals (custos diverges):** upstream reports every final class
  even in projects that install dg/bypass-finals, where mocking final classes
  works (hundreds of false positives on such test suites). custos skips FINAL
  when `\DG\BypassFinals` is in the project index (E8). Whether the tool is
  enabled at runtime, and for which paths, is not checked.
- **Method name case (custos diverges):** upstream compares the factory
  method names (and the chained `getMock`) case-sensitively, so
  `$this->CreateMock(Sealed::class)` escapes the check although PHP calls
  the same method. custos compares them case-insensitively (D1, D4).
- Variadic constructor parameters have no default value and therefore count
  as "required" for CTOR upstream; recommendation: treat variadic parameters
  as optional (no fixture covers it).
- String class names are always resolved as fully-qualified names, never
  relative to the current namespace (matches PHP's runtime behaviour).
- **Default values in Part B (custos diverges):** upstream also walks the
  parameter's default value, so `function it_works($max = Sealed::LIMIT)`
  is reported although nothing is mocked there (a constant of a final class
  is a plain value). custos inspects only the parameter type (D6).
- **Part B helper methods (custos diverges).** Upstream walks every method
  of the specification, but PhpSpec builds doubles only for the parameters
  of `let()`, `letGo()` and the examples (names starting with `it` or `its`
  followed by a non-letter: `it_charges`, `its_total`). Other methods are
  helpers the specification calls itself with real objects
  (`private function makeEvaluation(ProductUuid $uuid)`), so a final class
  there is not mocked. custos checks only those methods in D6 (13 Akeneo
  false positives at error severity).
