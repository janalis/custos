# ArgumentCountMismatch implementation notes

## Resolution

`semanticquery.ResolveCallee` gates every call first: it rejects dynamic
names, receivers that are not only classes, union receivers whose classes
disagree, and functions declared several times with different parameters.
The rule then lists the targets itself (nominal method plus the overrides
of every subtype from `Index.ChildrenAll`, as `UnknownNamedArgument` does)
and requires `semanticquery.HierarchyResolved` and a single declaration
for each class involved. A call is reported only when every target leaves
a required parameter unbound, so an override with a default or a variadic
parameter keeps it silent.

## Builtin parameter counts

The phpstorm-stubs write overloaded builtins as one signature, often with a
parameter required that PHP makes optional (`array_keys`, `strtr`,
`mt_rand`, `stream_filter_append`), and model pre-8.0 signatures loosely.
`builtins.go` therefore trusts a builtin only from PHP 8.0, only in the
directories of bundled extensions, and never when it is listed in
`driftedStubs`.

`driftedStubs` was generated by comparing, for every function and every
method a class declares itself, the required and total parameter counts
of PHP 8.5's reflection (`ReflectionFunction` / `ReflectionMethod`:
`getNumberOfRequiredParameters`, `getNumberOfParameters`, `isVariadic`,
with every bundled extension loaded) against the stub declaration at
PHP 8.5, keeping the names of the bundled directories that differ. Rerun
the comparison when the stubs are updated (`make stubs`) and replace the
list; a new PHP release can add entries.
